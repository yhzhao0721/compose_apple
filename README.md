# 合成苹果乐

基于 https://github.com/guguguing/compose_qu 的独立衍生版本，保留原始 Git 历史。

试玩地址：https://yhzhao0721.github.io/compose_apple/

网站仓库：https://github.com/yhzhao0721/compose_apple （独立仓库，并非 GitHub 平台关联 fork）。

## 运行

电脑可直接打开 `index.html`，图片与 Matter.js 0.20.0 都在本地，不需要 CDN。也可在此目录运行 `python3 -m http.server 8080`，然后打开 http://localhost:8080 。手机、微信试玩需通过能访问的 HTTP/HTTPS 地址打开，不能访问电脑上的文件路径；对外分享建议使用 HTTPS 静态托管并上传完整目录。

## 图片自定义

在侧栏「图片自定义」中：

- 过程图片：一次多选至少 9 张图片。每局从所选图片中无放回随机抽取 9 张，随机分配到第 1～9 级。
- 最终图片：单独选择 1 张，固定用于第 10 级。两项可独立设置，未设置的部分继续使用默认图片。
- 更改从下一局生效。开局前选图后点击「开始游戏」；游戏中选图会暂停，点击「换一局」并确认使用新设置，也可继续原来的一局。
- 「恢复默认图片」在下一局恢复默认的 15 位角色与苹果乐。
- 支持 JPG / JPEG、PNG、GIF、WebP、BMP、SVG 等浏览器可读取的图片，可混合选择，不区分扩展名大小写；动图作为静态头像使用。AVIF、HEIC 等格式能否读取取决于浏览器，无法读取时请先转换为 JPG / PNG / WebP。
- 不足 9 张、损坏或浏览器不支持的图片会提示错误，保留之前完整的设置。取消文件选择不改变设置。
- 图片只在浏览器本机处理，不上传；刷新或关闭页面后恢复默认。导入时依次解码并居中裁成最大 512 × 512 的缩略图，游戏中仍等比例裁圆。

## 规则

- 首次合成苹果乐时播放完整《Heavenly Me》，每局只自动触发一次；平时不显示音乐卡片或预告，只有成功后播放受限时才显示播放按钮。暂停游戏或切后台暂停音乐，重新开局停止音乐。音乐不随物理倍率加速。
- 开始游戏时尝试在用户点击手势中准备音频；若浏览器仍阻止自动播放，侧栏显示手动播放提示。来源记录见 `assets/AUDIO_SOURCE.md`。

- 默认每局从 `assets/characters/` 的 15 位普通角色中，无放回随机抽取 9 位，顺序也随机。
- 第 10 级默认为 `苹果乐.jpg`，可自定义替换；两枚第 9 级合成苹果乐，苹果乐不再升级，最终半径仍为 121。
- 投放冷却 50 毫秒，物理倍率为 8，与本地快速测试版一致；碰撞与滚动同步加速，音乐保持正常速度。
- 直接投放仅生成本局前 3 级。合成得分按新等级计，最佳分保存在 `composeAppleBest`，与原游戏独立。
- 首次开始、确认换一局、结束后再来一局会重新抽选；暂停、缩放、旋转不换阵容。
- 图片在 Canvas 与预览中等比例居中裁圆，不拉伸。全部图片加载完成才能开局。
- 合成路线只显示图片和等级编号。合成苹果乐后，画布背景切换为 `assets/victory-background.jpg`；侧栏可实时调整透明度（默认 65%，0% 完全显示、100% 完全透明），新一局恢复普通背景。

## 跨端处理

- 固定 520 × 700 游戏坐标，CSS 根据可用屏幕适配，支持小一点／自动／大一点；显示比例不改变物理难度。
- 手机单列、桌面双列、横屏紧凑布局；安全区留白，Visual Viewport 地址栏高度变化处理，保留页面缩放与游戏区外滚动。
- Pointer Events 拖动、捕获和取消处理；旧内核 Touch Events 回退，抑制重复点击。键盘左右瞄准、空格或 Enter 投放。
- 每个 60 Hz 游戏时钟步推进八次固定物理步长；冷却、出生保护期和危险线超时按未加速的游戏时间计时。限制后台恢复时补算；切后台暂停并需手动继续。
- 高分屏 Canvas 像素倍率限制在 2，降低手机绘制成本。图片预加载、错误反馈与存储异常容错。
- 合成队列在物理求解后处理，防止同一物体重复参与合成。

微信使用系统或内置网页内核；这里按能力检测提供通用适配，不依赖微信 SDK。浏览器模拟不能代替 Android、iOS 微信真机测试。

## 文件

- `index.html`：界面与入口。
- `style.css`：布局、移动端、安全区及控件。
- `game.js`：随机抽选、自定义设置、物理、绘制、输入和生命周期。
- `custom-images.js`：本地图片解码、缩略图处理与输入校验。
- `assets/characters/`：本版本 16 张原始用户图片；旧 `fruit-*` 仅保留为上游素材，不参与游戏。
- `vendor/matter.min.js`、`vendor/LICENSE`：固定版本物理引擎与 MIT 许可证。
